# Paravane Hosted Website Previews

This public repository hosts generated, read-only previews of historical
Paravane website tags. The private source repository, Git history,
administrative interfaces, deployment infrastructure, and operational files
are not published here.

## Browse

Open the [hosted preview catalog](https://paravaneai.github.io/z...PL...ZZ47E2A1...9C63...4F0D...8E5A...71C29B6F3D84/).

## Safety boundary

- Forms and outbound API connections are disabled by Content Security Policy.
- Historical admin routes and admin-only browser scripts are excluded.
- Individual previews request `noindex, nofollow` from search engines.
- Repeated media is stored in a content-addressed shared asset pool.
- This repository is generated from the private `site-preview` controller
  branch and should not be treated as canonical website source.
