# Retired Pages

These HTML pages are temporarily archived while the live site focuses on Email Intelligence.

To bring a page back later:
1. Move the file from this folder back to its original public path.
2. Set the matching `theme.pages.items.<pageKey>.enabled` value to `true` in `theme/brand-theme.js`.
3. Review the page copy before publishing it again.

The live site hides links to disabled pages from the centralized theme logic.
