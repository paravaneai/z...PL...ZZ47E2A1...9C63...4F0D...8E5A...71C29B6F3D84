Responses

Understand smtpRS results.

Responses include a decision, a normalized risk score, plan context, model context, and usage accounting. Full layer details are available only to entitled tiers.

Overview Quickstart Authentication Analyse endpoint Responses Errors Plans and limits Changelog

Core fields.

Field Type Description
overall_risk integer, 0 to 10 Aggregate risk score. Higher means riskier.
decision string allow, manual_review, or reject.
tier string Plan attached to the API key, such as FREE, BASIC, or PRO.
charlstm boolean Whether the LSTM local-part model was enabled for the request.
analysis_profile string mini, full, strict, or catch_all.
credit_cost integer Credits charged for this scoring profile.
usage object Current monthly credit window, used credits, remaining credits, and rate-limit context.

Decision values.

Decision Typical meaning Suggested action
allow The signal set does not indicate high risk. Continue your normal workflow.
manual_review The address or domain has ambiguous or elevated signals. Queue for review, request more context, or add friction.
reject The signal set indicates strong risk or invalid structure. Block, deny, or require a safer alternate email depending on your policy.

Summary response.

Free and Basic workspaces receive a summary response. Layer internals are intentionally omitted.

Summary response
{
  "overall_risk": 2,
  "decision": "allow",
  "tier": "BASIC",
  "charlstm": false,
  "analysis_profile": "full",
  "credit_cost": 3,
  "credits_charged": 3,
  "response_profile": "summary"
}

Full response.

Pro and higher tiers may receive layer details when the workspace has full layer export entitlement. Layer payloads are designed for operational review and debugging, not as stable contractual fields for hardcoded business logic.

Full response shape
{
  "layers": {
