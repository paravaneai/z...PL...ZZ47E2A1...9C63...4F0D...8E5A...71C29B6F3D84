Plans and limits

Credits and features by tier.

Each API key belongs to a workspace. The workspace plan controls monthly credits, request rate, number of active API keys, scoring profiles, and response depth.

Quota behavior.

Credits are counted in a calendar-month UTC window. If a request would exceed the active monthly limit, the API returns 429 with a structured monthly_credit_limit_exceeded response. Rate limits are enforced by the API and front-door server controls.
