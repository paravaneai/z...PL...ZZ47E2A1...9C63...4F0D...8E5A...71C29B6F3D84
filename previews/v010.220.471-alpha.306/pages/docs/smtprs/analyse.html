Endpoint

Analyse an email address.

The analyse endpoint validates an email address, runs the eligible smtpRS scoring profile, and returns a risk decision with credit usage.

Overview Quickstart Authentication Analyse endpoint Responses Errors Plans and limits Changelog

Request.

POST https://api.paravane.io/v1/analyse
Body field Type Required Description
email string, email format Yes Email address to score.
tenant_id string No Legacy/test fallback only. Normal tenant context comes from the API key.
JSON body
{
  "email": "alice@example.com"
}

Query parameters.

Parameter Default Profile Notes
disposable_only false mini Runs the lighter L1/L2/L3/L6 flow. Costs 1 credit.
strict_disposable false strict Adds deeper passive checks. Costs 5 credits and requires eligible tier.
guess false strict Escalates gray-zone cases. Costs 5 credits and requires eligible tier.
run_catch_all false catch_all Runs catch-all SMTP checks when enabled. Costs 20 credits and requires approval.
fast false same as request Uses shorter DNS/MX timeouts for latency-sensitive calls.

Examples.

Mini score
curl -X POST "https://api.paravane.io/v1/analyse?disposable_only=true" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: pvn_live_your_key_here" \
  -d '{"email":"alice@example.com"}'
Full score
curl -X POST https://api.paravane.io/v1/analyse \
  -H "Content-Type: application/json" \
  -H "X-API-Key: pvn_live_your_key_here" \
  -d '{"email":"alice@example.com"}'
Strict score
curl -X POST "https://api.paravane.io/v1/analyse?strict_disposable=true" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: pvn_live_your_key_here" \
  -d '{"email":"alice@example.com"}'

Feature gates.

The API checks the workspace plan and entitlements before running a scoring profile. If a requested profile is not available, the API returns a 403 with a structured feature_not_available detail.
