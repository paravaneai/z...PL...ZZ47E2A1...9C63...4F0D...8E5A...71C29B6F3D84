Quickstart

Your first smtpRS request.

Create an account, generate an API key, and call the analysis endpoint with a single email address.

Overview Quickstart Authentication Analyse endpoint Responses Errors Plans and limits Changelog

1. Get access.

  1. Create a Paravane Labs account from the signup page.
  2. Verify your email address.
  3. Wait for review if your account is not automatically approved.
  4. Sign in and open the API keys page.
  5. Create a key and copy it immediately. Raw API keys are only shown once.
Create account Open API keys

2. Send a request.

POST https://api.paravane.io/v1/analyse
curl
curl -X POST https://api.paravane.io/v1/analyse \
  -H "Content-Type: application/json" \
  -H "X-API-Key: pvn_live_your_key_here" \
  -d '{"email":"alice@example.com"}'
Python
import requests

response = requests.post(
    "https://api.paravane.io/v1/analyse",
    headers={
        "Content-Type": "application/json",
        "X-API-Key": "pvn_live_your_key_here",
    },
    json={"email": "alice@example.com"},
    timeout=15,
)
response.raise_for_status()
print(response.json())
JavaScript
const response = await fetch("https://api.paravane.io/v1/analyse", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-API-Key": "pvn_live_your_key_here"
  },
  body: JSON.stringify({ email: "alice@example.com" })
});

if (!response.ok) {
  throw new Error(`smtpRS request failed: ${response.status}`);
}

const result = await response.json();
console.log(result);

3. Read the result.

The most important fields are overall_risk, decision, analysis_profile, credit_cost, and usage. Basic plans receive a summary response. Higher tiers may receive full layer details when entitled.

Example summary response
{
  "overall_risk": 2,
  "decision": "allow",
  "tier": "BASIC",
  "charlstm": false,
  "analysis_profile": "full",
  "credit_cost": 3,

  "response_profile": "summary",
  "usage": {
    "limit": 10000,
    "used": 21,
    "remaining": 9979,
    "window": "calendar_month_utc"
  }
}
